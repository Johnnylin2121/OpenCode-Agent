# OpenCode 执行边界

1. Vault 文件只读；禁止自动创建、修改、移动、删除或回写任何 Vault 文件。
2. 默认在对话中输出检测结果；需要持久化时只写入 OpenCode 专属非 Vault 目录。
3. 仅在用户实际触发时读取行情或联网资料；本 skill 本身不主动拉取实时行情。
4. 使用内置 `read`、`glob`、`grep` 和用户明确授权的本地工具；不调用 MiMo、DSH 或 Obsidian 专用工具。
5. 所有缺失输入必须明确列出，不用推测补齐。

# 实时矛盾检测

## 定位

本 skill 专注近 3 个交易日加当日的即时矛盾检测。全 vault 长期扫描是独立任务，必须由用户另行明确触发；本 skill 不自动扩展扫描范围。

## 触发条件

- 用户说“检查矛盾”“有没有前后矛盾”“矛盾检测”；
- 用户在盘后复盘上下文中明确要求执行；
- 不创建后台任务，不在无人值守时自动执行。

## 执行流程

### Step 1: 收集比对数据

输入可以是用户明确提供的文件，也可以是已获准读取的 Vault 文件。`{VAULT_PATH}` 仅作为只读输入根目录，不得作为输出目录。缺少任一关键文件时，列出缺失项并停止，不自行创建或补写。

读取以下文件（章节号对齐 trading-daily-review 模板）：
1. **前日复盘**：`{VAULT_PATH}/交易体系/每日复盘/{前日} 每日复盘.md`
   - 提取"可验证假设"（§十二）
   - 提取"明日关注点"（§八）
   - 提取板块判断（§五 板块表现）
   - 提取量能判断（§一 大盘与量能）
2. **前前日复盘**：`{VAULT_PATH}/交易体系/每日复盘/{前前日} 每日复盘.md`
   - 同样按 §十二/§八/§五/§一 提取
3. **当日复盘**（刚生成的）
   - 提取板块判断（§五）、量能判断（§一）、核心驱动（§四）
4. **交易计划**：扫描 `{VAULT_PATH}/交易体系/交易计划/` 下 `当前持仓.md` 底档 + 各 `标的-方向-计划名称.md`
   - 取"状态：🟢 持仓中"的标的，提取其「决策依据 / 失效条件」逻辑状态
5. **记忆总表**：`{VAULT_PATH}/交易体系/交易记忆/00-交易记忆总表.md`
   - 提取 A 区判据（量能 v2 等）、B 区模式、C 区铁律的"当前有效版本"——作为维度五的裁决基准

### Step 2: 执行四维检测

**维度一：预判 vs 实际**
- 从前日复盘"可验证假设"中提取每个假设的验证标准
- 对比当日复盘中的实际数据
- 标记偏差 > 5% 的预判为矛盾
- 偏差 2%-5% 标记为偏离（⚠️）
- 偏差 < 2% 标记为一致（✅）

**维度二：板块判断连贯性**
- 提取近3日复盘中对同一板块的判断
- 检测是否存在以下模式：
  - 前日"看多"→ 今日"看空"，但未说明转变原因
  - 前日"领涨"→ 今日"弱势"，但无归因分析
- 不算矛盾的情况：明确引用了新数据/新事件说明转变

**维度三：持仓逻辑一致性**
- 读取 `交易计划/` 下各持仓标的计划文件的"决策依据/失效条件"状态（Step 1.4 已收集）
- 对比当日复盘中对该标的所属板块的判断
- 矛盾模式：
  - 复盘称"XX板块承压"，但该板块持仓逻辑仍为 ✅
  - 复盘称"XX板块走强"，但该板块持仓逻辑已为 ❌

**维度四：量能判断一致性**
- 对比近3日的量能状态描述（确立/试探/萎缩）
- 检测是否存在状态跳跃但缺乏过渡说明
- 例如：前日"萎缩"→ 今日"确立"，但成交额变化不足 15%

**维度五：今日判断 vs 记忆先例对照（2026-09-07 立，2026-09-07 晚修正定位）**
- 将当日复盘/盘中验证中的关键判断与 `00-交易记忆总表.md` A/B/C 区"当前有效版本"逐条比对
- 偏离模式示例：
  - 当日把"放量"直接等同于"反弹确认" → 偏离 A2 量能判据 v2（放量+收高双条件）
  - 当日对单日爆量板块给出追入倾向 → 偏离 B1 二日游（T+1 熄火 2/3）
  - 当日判断"恐慌"但量能缩量 → 偏离 A3（恐慌=放量+1:5 双条件）
  - 当日加仓评估忽略弹药预算 → 偏离 C9 弹药先行
  - 当日动作依据"盘中触线" → 偏离 C1 收盘口径第一性
- 输出：偏离条目 + 总表实证次数 + 历史案例链接 + 适用性提示
- ⚠️ **定位声明（记忆 = 先验参考，非裁决标准）**：记忆是历史归纳，不确保对任何新情况都适用。偏离记忆 ≠ 犯错——两种可能：①无意识重蹈覆辙（记忆救场）②**市场结构已变，旧模式失效（记忆需要演化）**——A4 绝对量能门槛在低量能时代失效即活例。判定权在当下数据与人工复盘，不在记忆。偏离 + 当下数据支撑且逻辑自洽 → 标记为"潜在新模式"，走记忆演化流程（增量更新 → consolidate 五类归因），而非强制服从记忆

### Step 3: 生成检测报告

默认直接在对话中输出，不嵌入或回写任何 Vault 文件。若用户明确要求非 Vault 文件，使用 OpenCode 专属输出目录，并在报告中注明路径。

```markdown
## 矛盾检测

### 检出矛盾 (X条)

1. **[类型标签] 简要描述**
   - 来源: 文件路径 §章节
   - 矛盾内容: 具体对比
   - 建议: 如何处理

### 偏离提醒 (Y条)

1. **[类型标签] 简要描述**
   - 来源: 文件路径 §章节
   - 偏离程度: 具体数据
   - 建议: 关注但无需立即处理

### 无矛盾项
- 预判验证: ✅ X/Y 通过
- 板块判断连贯: ✅
- 持仓逻辑一致: ✅
- 量能判断连贯: ✅
- 记忆先例对照: ✅（偏离 N 条待人工裁决）
```

类型标签：
- `[预判偏差]` — 假设验证不通过
- `[板块翻转]` — 板块判断前后矛盾
- `[逻辑不一致]` — 持仓逻辑与板块判断矛盾
- `[量能跳跃]` — 量能状态突变无说明
- `[记忆偏离]` — 当日判断与记忆先例不一致（维度五，附实证次数与历史案例；**偏离 ≠ 违规**，需人工裁决是重蹈覆辙还是市场结构已变）

### Step 4: 后续处理

1. **矛盾项**：强制要求在复盘"思维引导"（§十 必问问题）中回应——预判错误落到第2题「前几日预判，哪些错了？」，意外情况落到第3题「今天有什么是我没预判到的？」
2. **逻辑不一致**：报告提醒用户审查对应标的计划文件（`交易计划/标的-方向-计划名称.md`）的逻辑状态，不自动改文件
3. **偏离项**：记录但不强制处理

## 边界规则

- 只检测近3个交易日的数据，不做长期追溯
- 板块判断转变有明确新数据/新事件支撑的，不算矛盾
- 预判偏差 < 2% 的不标记
- 不自动修改任何文件，尤其禁止写入 Obsidian Vault
- 不主动联网、不创建后台任务、不读取账户或凭据
- 只生成对话报告或经用户指定的非 Vault 结果
