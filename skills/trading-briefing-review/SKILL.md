# OpenCode 执行边界

1. Obsidian Vault 只读；禁止创建、修改、移动、删除或回写任何 Vault 文件。
2. 默认在对话中输出复核报告；需要持久化时只写入 OpenCode 专属非 Vault 目录。
3. 自动层文件可以是 `trading-briefing-fetch` 的 OpenCode 输出，也可以是用户明确提供的文件。
4. 仅在用户实际触发时使用公开 `webfetch` 或 `websearch` 核验事实；不访问账户和凭据。
5. 不依赖 MiMo、DSH、Obsidian 或 domain-memory 专用工具；记忆读取使用只读文件搜索。
6. 输入缺失时列出缺失项并停止，不创建占位文件。

# 早读复核 (briefing-review)

## 定位与权限边界

- 对用户明确提供或获准读取的正式财经早读做第三方审阅；
- 默认只输出复核结果，不生成或写入 Vault 文件；
- 审阅姿态：不反驳、不支持、不生成新观点，只做客观标注；
- 正式早读的修订权始终属于用户。

## 输出模板（三节）

默认直接输出到对话；不创建 `早读复核` 文件。若用户明确要求非 Vault 文件，才使用 OpenCode 专属输出目录。

```
# 早读复核 - {日期}
> 复核基准时点：开盘前（09:15）可得信息 · 复核执行时间：{timestamp}
> 复核覆盖率：行情表 {n}/{m} 项 · 事实类 {k}/{t} 项（webfetch / 检索核查）
> 覆盖范围外（不判定对错）：主观解读、docx 独有非公开信息（此部分走第二节记忆审阅）

## 一、数据复核（四态判定）
| 正式稿项 | 正式稿值 | 自动层/检索值 | 判定 | 说明（含时点标注） |

## 二、主观判断的客观审阅（逐条三态标注）
## 三、盲区标记（≤3 条）
```

### 四态判定规则（第一节）
- `一致`：偏差 <0.5% 或完全相符
- `口径差异`：时点/口径可解释（自动层=最近两根日线收盘 vs 正式=15:00→次日6:30），**不算错误**
- `过时-需修正`：正式稿发布时无误，但以开盘前最新信息看已变化 → 附最新值+时间戳（哪怕不是错误也要修正）
- `疑似错误`：超出时点可解释范围且无法解释 → 给出证据与建议核实方向
- 每项必须带时点标注；复核若在盘中/盘后执行，禁止用盘中数据倒推正式稿"错误"（基准=开盘前）

### 记忆审阅规则（第二节，硬约束）

第二节只读取引擎提供的记忆总表或用户明确提供的记忆文件；不要求 domain-memory 插件，不写入任何记忆文件。若没有记忆总表，所有主观判断标记 `【记忆-无覆盖】`。

- 引用格式：条目编号 + 实证次数 + 版本日期；
- 总表未覆盖时，不自行翻查归档文件补齐结论；
- 记忆是先验参考，不是裁决标准；
- 发现总表可能滞后时，只在报告尾注提示，不代写。

记忆无覆盖时的**常识辅助**（约束）：
- 强制标签 `【常识-非记忆】`，与记忆引用明确区分
- 仅两类用途：① 事实性 sanity check（数字加总、因果链硬伤才出手）② 标注"偏离市场共识的程度"——**不评对错**，反共识本身当信息呈现（提示"此处与市场共识相反，是有意还是疏忽请自查"）
- 禁止用市场平均观点否定用户的独立判断
- 常识判断连续多次与后续复盘结论相反 → 反向沉淀为交易记忆（负样本），该类常识让位

### 盲区标记规则（第三节）
正式早读未提及、但同时满足以下两条的信息：
- 六类关注方向命中：商品 / 存储AI / 美股宏观 / 地产银行 / 地缘 / IPO打新
- 显著性阈值：商品单日涨跌 >2%、指数新高/新低、利率关口（如 30Y 破 5%）、政策落地、地缘升级
- **最多 3 条**；候选超过 3 条 → 判定阈值过松，先收紧阈值再输出
- 每条附：为何重要 + 跟踪字段（后续 3 日是否成为正式早读主题/盘面主线：命中/未命中）

## 定期校准（每 10 个交易日或并入周度复盘）
- 回看历史复核文件第三节，统计盲区命中率；命中率低 → 修改本 skill 阈值定义（注明调整日期与依据，版本化）
- 同时统计第一节的误报率（把口径差异误判为疑似错误的次数）

## 与其他 skill 的分工

- `trading-briefing-fetch`：只提供自动数据层输入；
- `trading-contradiction-check`：负责跨日逻辑矛盾；
- 本 skill 只负责当日事实和判断复核；
- 全 vault 扫描不由本 skill 自动执行；
- 记忆只读，不在本 skill 中沉淀或写入。

## 执行纪律

- 手动触发，不创建后台任务；
- 任何输入缺失都明确报告；
- 结果默认只在对话中展示；
- 不修改正式早读、自动层文件或任何 Vault 文件。
