# Third-party notices

This repository contains adapted workflows and optional upstream references. The root MIT license covers original repository material, not automatically every third-party skill or copied excerpt.

- `caveman`, `caveman-commit`, `caveman-help`, `caveman-review`, and `caveman-compress`: upstream references are documented in each skill; verify the upstream license before redistribution.
- `find-skills`: based on the skills ecosystem workflow; verify the CLI and skill package licenses before redistribution.
- `grill-me`: source and redistribution terms must be confirmed by the repository owner.
- `trading-value-investing`: methodology and teaching materials require source and copyright review; current chapters are marked as abbreviated.
- `browser-skill`: adapted from the BrowserSkill project; verify the upstream license and version before redistribution. The repository copy excludes local source markers and lock state.
- Public market and web integrations are user-triggered and depend on third-party services; no third-party account data belongs in this repository.

Before adding a new external skill, record its source, version or commit, license, review date, and whether it is safe to redistribute.
